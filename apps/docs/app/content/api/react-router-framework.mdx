# @skyscribe-sdk/react-router-framework

Loader factories and meta helpers for React Router v7/v8 framework mode. Install with `npm install @skyscribe-sdk/react-router-framework`. See the [React Router guide](/frameworks/react-router) for walkthroughs.

## Functions

### `createSiteLoader`

```ts
function createSiteLoader(
  author: string,
  publicationUrl: string,
  deps?: { fetchSite?: typeof fetchSite }
): (args: LoaderFunctionArgs) => Promise<Site>
```

Returns a React Router loader that fetches a Site. It passes `request.signal` through, so the fetch is cancelled if the visitor navigates away.

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `author` | `string` | Author handle or DID |
| `publicationUrl` | `string` | The site's canonical HTTPS URL, e.g. `"https://alice.bsky.social"` |
| `deps.fetchSite` | `function` | Optional. Replaces the fetch function, for testing |

```ts
// app/routes/blog.tsx
export const loader = createSiteLoader('alice.bsky.social', 'https://alice.bsky.social');
```

### `createArticleRouteLoader`

```ts
function createArticleRouteLoader(
  author: string,
  publicationUrl: string,
  slugParam?: string,
  deps?: { fetchArticleBySlug?: typeof fetchArticleBySlug }
): (args: LoaderFunctionArgs) => Promise<ArticleWithUri>
```

Returns a React Router loader that reads the article's slug from the route params, fetches the article and its AT URI with `fetchArticleBySlug`, and returns an `ArticleWithUri`. It passes `request.signal` through.

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `author` | `string` | Author handle or DID |
| `publicationUrl` | `string` | The site's canonical HTTPS URL, e.g. `"https://alice.bsky.social"` |
| `slugParam` | `string` | Optional. URL param name to read the slug from. Defaults to `"articleSlug"` |
| `deps.fetchArticleBySlug` | `function` | Optional. Replaces the fetch function, for testing |

```ts
// app/routes/blog.$articleSlug.tsx
export const loader = createArticleRouteLoader('alice.bsky.social', 'https://alice.bsky.social');

// custom param name:
export const loader = createArticleRouteLoader('alice.bsky.social', 'https://alice.bsky.social', 'slug');
```

The loader throws an `Error` if the slug param is missing (a route set-up mistake), and `NotFoundError` from `@skyscribe-sdk/core` if no published article has that slug. Catch `NotFoundError` and throw a 404 `Response` if you want React Router's 404 handling.

### `createWellKnownLoader`

```ts
function createWellKnownLoader(
  author: string,
  publicationUrl: string,
  deps?: { resolvePublicationUri?: typeof resolvePublicationUri }
): (args: LoaderFunctionArgs) => Promise<Response>
```

Returns a React Router loader that responds with the Site's AT URI as plain text. Serve it at `/.well-known/site.standard.publication`, where `site.standard` apps look to confirm that a website belongs to a Publication.

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `author` | `string` | Author handle or DID |
| `publicationUrl` | `string` | The site's canonical HTTPS URL |
| `deps.resolvePublicationUri` | `function` | Optional. Replaces the lookup function, for testing |

```ts
// app/routes.ts
route(".well-known/site.standard.publication", "routes/well-known-publication.ts"),

// app/routes/well-known-publication.ts
export const loader = createWellKnownLoader('alice.bsky.social', 'https://alice.bsky.social');
```

### `articleMeta`

```ts
function articleMeta(article: Article, site: Site): MetaDescriptor[]
```

Returns a `MetaDescriptor[]` to spread into a React Router `meta` function: the title, canonical link, Open Graph and Twitter Card tags, and JSON-LD structured data (the same set as core's `generateArticleMeta`).

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `article` | `Article` | The full article object |
| `site` | `Site` | The site object |

```ts
import { articleMeta } from '@skyscribe-sdk/react-router-framework';
import type { Route } from './+types/Article';

export function meta({ loaderData }: Route.MetaArgs) {
  if (!loaderData) return [{ title: 'My Blog' }];
  return [
    ...articleMeta(loaderData.article, loaderData.site),
    { title: `${loaderData.article.title} — My Blog` },
  ];
}
```

Spread it first, so your own `{ title }` at the end wins in the browser tab while the Open Graph tags keep the plain article title. See the [meta tags guide](/guides/meta-tags).

function siteMeta(site: Site): MetaDescriptor[]

## Testing

All three factories accept an optional `deps` argument, so you can pass mock functions directly instead of using `vi.mock`.

```ts
import { describe, it, expect, vi } from 'vitest';
import { createSiteLoader, createArticleRouteLoader, createWellKnownLoader } from '@skyscribe-sdk/react-router-framework';

describe('blog loaders', () => {
  it('fetches the site', async () => {
    const fetchSite = vi.fn().mockResolvedValueOnce(mockSite);
    const loader = createSiteLoader('alice.bsky.social', 'https://alice.bsky.social', { fetchSite });
    const result = await loader({ request: new Request('https://example.com'), params: {}, context: {} });
    expect(result).toEqual(mockSite);
    expect(fetchSite).toHaveBeenCalled();
  });

  it('fetches an article by slug', async () => {
    const fetchArticleBySlug = vi.fn().mockResolvedValueOnce({ article: mockArticle, uri: mockUri });
    const loader = createArticleRouteLoader('alice.bsky.social', 'https://alice.bsky.social', 'articleSlug', { fetchArticleBySlug });
    const result = await loader({ request: new Request('https://example.com'), params: { articleSlug: 'hello' }, context: {} });
    expect(result).toEqual({ ...mockArticle, documentUri: mockUri });
  });
});
```

## Types

### `ArticleWithUri`

The return type of `createArticleRouteLoader`: an `Article` plus the AT URI of its record.

```ts
interface ArticleWithUri extends Article {
  documentUri: string;  // AT URI, e.g. "at://did:plc:…/site.standard.document/3mp47vvkh342n"
}
```

Pass `documentUri` to `@skyscribe-sdk/social`'s buttons.

The main types from `@skyscribe-sdk/core` are re-exported too:

```ts
import type { Site, Article, ArticleRef, SiteGroup, ArticleWithUri } from '@skyscribe-sdk/react-router-framework';
```

See the [core reference](/api/core#types) for full type definitions.
